## 人工与 Codex 分歧

### S08

- 人工选择 main：认为拆年假陪诊、临时健身卡和视频煮面形成更完整的生活过程，且没有明显缺陷。
- Codex 选择 V2/r4：更看重 85 万元目标、调休陪诊和“气色好多了”带来的克制生活反馈。
- 分歧原因：双方关注的是不同细节组合；人工更偏好连续生活动作，Codex 更偏好目标—行动—反馈的结构。人工把握度为中，应视为边缘样本。

### S10

- 人工选择 main：认为面馆定约、高铁站送别和错过通话争吵构成完整情绪弧，且自然度明显更高。
- Codex 选择 V2/r4：更看重住院陪护、轮流守夜和走廊谈话形成的情绪过程。
- 分歧原因：V2/r4 有更细的照护过程，但财务模板句破坏自然度；人工对模板干扰的惩罚明显高于 Codex。该分歧说明模板句不是轻微观感问题，而可能直接逆转整组胜负。

## 验收判断

人工结果支持以下较保守结论：

> V2/r4 整体文风质量高于 main 的概率更大，尤其在有效细节、情绪过程和余味方面；但优势尚未跨题材稳定复现，自然度存在可测的回退，模板化财务/状态句是首要修复点。

因此，当前可以继续采用 V2/r4 作为缓存布局候选，但不能据此宣布“文风全面优于 main”。下一步应先移除或改写错误复用的财务/状态模板句，再针对 S06、S10 以及两个职业题材做小规模同输入复测；不需要立刻执行完整 2/2/1。
