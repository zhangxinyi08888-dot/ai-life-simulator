# main 与 V2/r4 文风专项揭盲判定

## 结论

在 10 组同输入、真实模型成对生成中，V2/r4 文风盲评结果为 **8 胜、0 平、2 负**。七项文风评分总均值由 main 的 **3.414/5** 提升到 V2/r4 的 **3.829/5**，提升 **0.415 分**。

这构成了“V2/r4 没有以文风质量为代价，并出现方向明确的文风改善”的新证据，但还不能当作统计学上的最终证明：10 组二项符号检验双侧 `p = 0.109375`，样本量较小；两个职业题材检查点的两次重复均为 1:1，而三个生活/关系及创业压力题材均为 V2/r4 2:0。

因此，本轮最准确的判定是：

- V2/r4 在具体细节、人物声音、情绪细腻度和克制余味上有实质性改善信号；
- 改善在生活照护、承诺冲突和创业现实压力题材中重复出现；
- 职业相遇、产品交付题材尚不稳定，不能宣称所有题材都更好；
- 模板化总结没有被根除，自然度只小幅提升；
- 既有 `relationship-03` 的 `attributesRange` 失败仍是整体发布质量门槛，本轮没有否定该问题。

## 自动文体特征

自动统计只用于解释盲评，不单独决定质量。

| 特征 | main | V2/r4 | 观察 |
|---|---:|---:|---|
| 平均字符数 | 435.5 | 494.4 | V2/r4 平均长 13.5% |
| 平均段落数 | 7.6 | 8.4 | V2/r4 略多 |
| 平均句数 | 11.0 | 12.4 | V2/r4 略多 |
| 平均句长 | 37.89 | 38.87 | 基本接近 |
| 直接引语/千字 | 1.38 | 2.43 | V2/r4 高约 76% |
| 场景词/千字 | 3.21 | 4.45 | V2/r4 高约 39% |
| 数字/时间锚点/千字 | 3.21 | 3.44 | 接近，V2/r4 高约 7% |
| 总结脚手架/千字 | 5.97 | 6.67 | V2/r4 反而高约 12% |

这些数据支持两个同时成立的判断：

1. V2/r4 的细腻感不是纯粹来自“写得更长”。即使按字符数归一化，其直接引语与场景词密度仍明显更高；而且 V2/r4 在两组比 main 更短的样本中仍然胜出。
2. V2/r4 没有解决模板残留。总结脚手架密度反而略高，和盲评中自然度只增加 0.1 分一致。其优势是同样存在模板骨架时，场景、行动、对话和情绪过程更充分。

长度仍是潜在混杂项：V2/r4 在比 main 更长的 8 组中赢 6 组，在比 main 更短的 2 组中赢 2 组；同时也有一组 V2/r4 略长但仍输给 main。因此长度可能帮助表现，但不足以解释 8:2 的全部结果。

## 为什么 V2/r4 会出现这种变化

V2/r4 没有直接新增“写得更细腻”的风格指令，变化来自上下文布局：

- 稳定的用户事实和回答被移动到稳定 system 前缀；
- 动态 Story Context 不再重复完整事实和近期历史，而是引用前面的权威区段；
- 增加了内容完整性边界，要求引用前文时保留事实语义。

这不会改变模型、采样参数或核心任务，但会改变信息在上下文中的位置、重复程度和注意力竞争。模型对位置和上下文组织敏感；减少背景材料的重复铺陈后，稳定人物/关系事实更早、更集中，动态区域也给场景、行动和对话留下更多表达空间。这与本轮观测到的对话密度、场景词密度，以及关系/照护题材的重复胜出相符。

这是基于实现变化与输出特征的一致性推断，不是已经隔离所有中间变量的因果证明。要进一步确认，需要增加跨日、交错顺序的重复样本，或做只改一个布局因素的消融试验。

## 调用顺序与统计限制

- V2/r4 先生成的 5 组中，V2/r4 赢 5 组；V2/r4 后生成的 5 组中，V2/r4 赢 3 组。
- 因为每个检查点只有两次重复，不能区分调用顺序、时间波动和随机采样造成的影响。
- 8/10 胜的双侧符号检验 `p = 0.109375`，未达到常用的 0.05 阈值。
- 后续人工评审已完成：人工揭盲结果为 V2/r4 6:4 main，七维总均值为 3.329:2.729；人工与 Codex 的逐组胜者一致率为 8/10。人工结果仍支持 V2/r4 的整体改善方向，但显示跨题材复现弱于 Codex 初评。

## 验收判断

本轮支持以下结论：

> 对这 10 组固定输入，V2/r4 没有表现出文风退化，且在具体细节、人物声音、情绪细腻度和克制余味上呈现有意义的改善信号；这一优势在三类题材中完成两次重复，但尚不足以证明所有题材稳定提升。

人工复核已经支持 V2/r4 的整体方向，但自然度评分由 main 的 3.3 降至 V2/r4 的 2.9，且 S10 的模板句直接逆转人工胜负。下一步应针对两项剩余问题做窄范围处理：一是模板总结句，二是既有 `attributesRange` 失败；之后只复测受影响检查点，不需要立即跑完整 2/2/1。人工完整揭盲结果见 `human-unblinded-style-overview.md`。
