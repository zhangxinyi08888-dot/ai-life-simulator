# Candidate Patch 默认关闭后的真实模型验收

## 结论

通过。生产默认关闭 Candidate Patch 后，候选版本完成 3 类人物 × 3 轮 × 20 节点，共 9 条路线、180 个真实 AI 浏览器节点。性能、完整重生成、用户可见暂停、财务权威事实和完整历史结构门禁均通过。

本报告替代 2026-07-30 的 Patch 开启版报告作为当前发布证据。Candidate Patch 仍保留在 feature flag 后，不满足重新开启条件前不得在生产环境启用。

## 方法

- 人物：普通职业、关系/健康交错、财务/创业。
- 每类 3 轮，每轮 20 节点，共 180 个节点。
- 数据源：真实 DeepSeek 模型和真实浏览器页面；没有复用旧节点。
- 候选计时：用户选择后至下一个节点可交互的页面总耗时，包含模型调用、校验、Proposal repair、确定性回退和原子提交。
- 合入前控制组：P90 31,948 ms，完整重生成率 30%，用户可见暂停 0。
- 大型路线 JSON 保存在工作区外的发布证据目录，不进入 Git；机器汇总文件为 `performance-summary.json`。
